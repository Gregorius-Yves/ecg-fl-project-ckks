Modul Informasi Publik
1 Apa itu Federated Learning?
Metode kecerdasan buatan (AI) kolaboratif di mana beberapa rumah sakit melatih model secara bersama tanpa pernah bertukar rekam medis pasien. Yang dikirim bolak-balik hanyalah formula matematika (bobot model AI), sehingga privasi pasien terlindungi 100%.
💡 Analogi: 3 dokter menulis buku panduan diagnosis bersama hanya dengan berbagi ringkasan ilmu, tanpa membawa berkas rekam medis pasien keluar dari rumah sakit masing-masing.
2 Apa Guna Dashboard / Run Ini?
Sebagai Pusat Komando (Mission Control) otomatis yang mengorkestrasi pelatihan AI di 4 Virtual Machine nyata. Sistem mengatur jadwal ronde, mendistribusikan bobot via protokol Flower gRPC, memantau penggunaan RAM & CPU live, serta menyimpan model checkpoint terbaik (best.pt).
🎯 Fungsi: Menguji coba metode pembelajaran mesin secara otomatis, aman, dan dapat diulang kembali (reproducible).
3 Apa Eksperimen yang Sedang Diuji?
Menguji tolok ukur (benchmark) 6 algoritma FL (FedAvg, FedProx, SCAFFOLD, FedBN, FedBB, FedSOL) untuk mendeteksi 27 kelainan jantung pada sinyal 12-lead EKG menghadapi 3 tantangan dunia nyata (Non-IID):
  • Feature Shift: Beda merk alat & sampling sinyal.
  • Label Skew: Sebaran jenis penyakit tidak merata.
  • Duration Skew: Durasi rekam sinyal pasien berbeda.
4 Bagaimana 1 Ronde FL Bekerja?
Setiap ronde pelatihan berlangsung dalam 4 langkah siklus:
  1. Broadcast: Server mengirim model global ke 3 klien.
  2. Local Fit: Klien melatih model dengan data privatnya.
  3. Upload: Klien mengirim balik update bobot model ke server.
  4. Agregasi: Server menggabungkan update jadi model baru.
